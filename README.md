# Notisight | Akıllı Bilgi Asistanı Tanıtım Sitesi

Bu depo, **Notisight** uygulaması için tasarlanmış modern, hızlı ve duyarlı (responsive) tanıtım web sitesinin (landing page) kaynak kodlarını içerir.

## 🚀 Proje Hakkında

Notisight; notlarınızı, PDF belgelerinizi ve ses kayıtlarınızı tek bir akıllı bilgi alanında birleştiren yeni nesil bir bilgi asistanıdır. Kullanıcılar, dosyalar arasında kaybolmadan sadece soru sorarak aradıkları bilgilere kaynaklı bir şekilde ulaşabilir.

- **İki Farklı AI Modu:** Genel yapay zekâ (Standard Mode) veya kişisel bilgi havuzu tabanlı akıllı arama (Sight Mode).
- **Kaynaklı Cevaplar:** Yanıtların hangi belgeden ve nottan geldiğini şeffafça gösteren altyapı.
- **Çoklu Format Desteği:** PDF çözümleme, ses kayıtlarını deşifre etme ve zengin metin düzenleme yetenekleri.

## 🛠️ Teknolojiler

- **React 19** & **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Motion (Framer Motion)** & **Lucide Icons**

## 💻 Yerel Geliştirme (Local Development)

Proje kaynak kodunu yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

1. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

2. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```

3. Üretim sürümü derlemesi (Production Build) almak için:
   ```bash
   npm run build
   ```
